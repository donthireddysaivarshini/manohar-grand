# React Admin Panel Specification & Operations Matrix

## 1. Custom Admin Panel Strategy
- The primary operations console for hotel staff and management is a **purpose-built React Admin Application**, interacting with the Django REST Framework `/api/v1/admin/` endpoints.
- Django's built-in `/admin/` remains active solely for developer superuser emergency access and database debugging.

---

## 2. Core Functional Modules

### 2.1 Front Desk Live Operations Dashboard
- **KPI Tiles**: Today's Check-ins, Today's Check-outs, In-House Guests, Total Occupancy %, Vacant AC Rooms, Vacant Non-AC Rooms, Pending Cash Payments.
- **Arrivals & Departures List**: Quick check-in action (Aadhar verification toggle, physical room key assignment `AC-104`, checkout completion).
- **Walk-in / Phone Quick Booking Modal**: Instant reservation entry taking payment via cash, POS card terminal, or manual Razorpay link.

### 2.2 Interactive 28-Room Availability & Night Calendar
- Visual grid matrix: Rows = 28 Physical Rooms (`AC-01` to `AC-20`, `NAC-01` to `NAC-08`), Columns = Days of month.
- Color-coded cells:
  - Green = Available
  - Red = Confirmed Reservation (click to view guest & booking details)
  - Yellow = Temporary Checkout Hold
  - Grey = Out of Service / Maintenance Block
- Drag-and-drop or click-to-block maintenance toggle.

### 2.3 Reservations & Guest Management
- Comprehensive data grid with search, date filtering, category filtering, and status filtering (`held`, `confirmed`, `checked_in`, `checked_out`, `cancelled`).
- Reservation detail drawer: Lead guest contact details, Aadhar verification status, itemized `BookingPriceSnapshot`, payment transactions, assigned physical rooms, audit activity timeline.
- Actions: Modify stay dates, change room category, cancel booking, process refund, resend booking voucher.

### 2.4 Rates, Inventory & Rule Configuration
- Edit base rate per night for AC Rooms (baseline: ₹1,599) and Non-AC Rooms (baseline: ₹1,299).
- Configure Extra Adult (₹350) & Extra Child (₹300) surcharge amounts.
- Set GST tax percentages (baseline: 5%) and miscellaneous fee rules.
- Set seasonal / weekend rate overrides.
- Manage physical room inventory (activate/deactivate units, mark under maintenance).
- *Note*: Maximum occupancy limits (AC: 4, Non-AC: 2) are not freely editable by admins unless explicitly requested.

### 2.5 Admin Overbooking Override (SuperAdmin Only)
- Explicit capability for the Hotel Owner / SuperAdmin to force-create a booking even when a category is at zero availability.
- Mandatory justification text and immutable audit log entry capturing the user ID and timestamp.

### 2.6 Aadhaar & ID Document Verification (Future Phase)
- Secure, authenticated staff-only viewer for uploaded Aadhaar photo/scan.
- Documents are stored privately (never public URLs) and access is strictly audited.

### 2.7 Corporate & Bulk Inquiries Manager
- View incoming bulk requests from corporate clients.
- Set special negotiated per-night package rates.
- Convert approved corporate inquiries directly into confirmed block reservations.

### 2.8 Audit Log & Reporting Engine
- Daily revenue report, GST tax liability ledger, monthly occupancy rates, booking source breakdown (Online Direct vs. Walk-In vs. Phone vs. Corporate).
- Comprehensive `AuditLog` viewer showing timestamp, staff user, entity modified, old values, and new values.

## 3. Role-Based Access Control (RBAC) Matrix

| :--- | :---: | :---: | :---: |
| **View Dashboard & Calendar** | Yes | Yes | Yes |
| **Walk-in / Phone Bookings** | Yes | Yes | Yes |
| **Check-in / Check-out / Room Assign** | Yes | Yes | Yes |
| **View Guest Aadhaar Scans** | Yes | Yes | Yes (Active stays only) |
| **Dynamic Rate / Tariff Editing** | Yes | Yes | No |
| **Tax / GST Rule Configuration** | Yes | No | No |
| **Staff Account Management** | Yes | No | No |
| **Overbooking Override** | Yes | No | No |
| **Financial & Tax Audit Reports** | Yes | Yes (Partial) | No |
| **CMS Content Management** | Yes | No | No |
