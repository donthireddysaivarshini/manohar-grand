# RESTful API Specification & Endpoints Directory (/api/v1/)

## 1. Global API Standards
- **Base URL Namespace**: `/api/v1/`
- **Request / Response Format**: `application/json; charset=utf-8`
- **Standard Success Envelope**:
  ```json
  {
    "success": true,
    "data": { ... },
    "meta": { "timestamp": "2026-10-10T12:00:00Z" }
  }
  ```
- **Standard Error Envelope**:
  ```json
  {
    "success": false,
    "error": {
      "code": "INVENTORY_EXHAUSTED",
      "message": "Only 2 AC Rooms available for the requested stay dates.",
      "details": { "available_count": 2 }
    }
  }
  ```
