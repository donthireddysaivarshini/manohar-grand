# Database Schema & Entity Relationship Design — Manohar Grand Hotel

## 1. Entity-Relationship Overview (Normalized 3NF Architecture)

The database schema is strictly normalized, maintaining referential integrity, explicit foreign key constraints, deletion protections (`PROTECT` for historical financial data), and optimized B-Tree indices.

```
+-------------------+       +-----------------------+       +------------------------+
|      User         | 1---1 |    CustomerProfile    |       |      StaffProfile      |
|  (Auth / Core)    |       | (City, State, History)|       | (Owner/Manager/Recept) |
+---------+---------+       +-----------------------+       +-----------+------------+
          | 1
          |
          | *
+---------v---------+       +-----------------------+       +------------------------+
|     Booking       | 1---* |     BookingRoom       | *---1 |      PhysicalRoom      |
| (Reference, Status|       | (Assigned Room, Night)|       | (Authoritative 28 Rms) |
| Token, 50% Advance|       +-----------+-----------+       +-----------+------------+
| Overbooking Flag) |                   |                                   | *
+---------+---------+                   |                                   | (1:N)
          | 1                           |                                   |
+---------v---------+                   |                   +---------------v--------+
|BookingPriceSnapshot                   |                   |      RoomCategory      |
|(Rate, Tax, Total) |                   |                   | (Derived Inventory)    |
+---------+---------+                   |                   +-----------+------------+
          | 1                           |                               | 1
          |                             |                               |
+---------v---------+                   |                               | *
|PaymentTransaction |                   |                   +-----------v------------+
|(Razorpay, Amount) |                   |                   |   RoomCategoryAmenity  |
+---------+---------+                   |                   | (Mattress, Smart TV...) |
          | 1                           |                   +------------------------+
          | *                           v
+---------v---------+       +-----------------------+       +------------------------+
|      Refund       |       |  BookingGuest / IDDoc |       |       TaxRule          |
| (Amount, Status)  |       | (Aadhaar Secure Doc)  |       | (GST 5% Baseline)      |
+-------------------+       +-----------------------+       +------------------------+
```

## 2. Comprehensive Model Definitions

### 2.1 Authentication & User Domain (`apps.authentication`)

#### `User` (Custom AbstractBaseUser)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `email`: `EmailField(unique=True, db_index=True)`
- `phone`: `CharField(max_length=15, blank=True, null=True, db_index=True)`
- `first_name`: `CharField(max_length=150)`
- `last_name`: `CharField(max_length=150)`
- `is_staff`: `BooleanField(default=False)`
- `is_superuser`: `BooleanField(default=False)`
- `is_active`: `BooleanField(default=True)`
- `auth_provider`: `CharField(max_length=20, default='email', choices=[('email','Email / Password'),('google','Google OAuth')])`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

#### `CustomerProfile`
- `id`: `UUIDField(primary_key=True, default=uuid4)`
- `user`: `OneToOneField(User, on_delete=models.CASCADE, related_name='customer_profile')`
- `city`: `CharField(max_length=100, blank=True)`
- `state`: `CharField(max_length=100, blank=True)`
- `notes`: `TextField(blank=True)`

#### `StaffProfile`
- `id`: `UUIDField(primary_key=True, default=uuid4)`
- `user`: `OneToOneField(User, on_delete=models.CASCADE, related_name='staff_profile')`
- `role`: `CharField(max_length=20, choices=[('receptionist','Front Desk Receptionist'),('manager','Hotel Manager'),('superadmin','Owner / Super Administrator')])`
- `employee_id`: `CharField(max_length=30, unique=True)`
- `is_active_duty`: `BooleanField(default=True)`

### 2.2 Room & Physical Inventory Domain (`apps.rooms` & `apps.inventory`)

#### `RoomCategory`
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `slug`: `SlugField(max_length=50, unique=True, db_index=True)` (e.g. `'ac-room'`, `'non-ac-room'`)
- `name`: `CharField(max_length=100)` (e.g. `'AC Room'`, `'Non-AC Room'`)
- `tagline`: `CharField(max_length=255, blank=True)`
- `description`: `TextField(blank=True)`
- `included_adults`: `PositiveIntegerField(default=2)`
- `included_children`: `PositiveIntegerField(default=0)`
- `max_adults`: `PositiveIntegerField(null=True, blank=True)`
- `max_children`: `PositiveIntegerField(null=True, blank=True)`
- `max_total_occupancy`: `PositiveIntegerField(default=4)` *(AC: 4 PAX; Non-AC: 2 PAX baseline, 3 PAX pending confirmation)*
- `display_order`: `PositiveIntegerField(default=0)`
- `is_active`: `BooleanField(default=True, db_index=True)`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

> [!IMPORTANT]
> **Inventory Source of Truth**: `PhysicalRoom` records are the sole authoritative physical inventory. `RoomCategory.total_physical_inventory` is strictly a derived/read-only model property:
> ```python
> @property
> def active_physical_room_count(self):
>     return self.physical_rooms.filter(operational_status='operational').count()
> ```

#### `PhysicalRoom` (Authoritative Units)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `category`: `ForeignKey(RoomCategory, on_delete=models.PROTECT, related_name='physical_rooms')`
- `room_number`: `CharField(max_length=20, unique=True, db_index=True)` (e.g. `'101'`, `'102'`; entered via staff admin setup)
- `floor`: `IntegerField(default=1)`
- `operational_status`: `CharField(max_length=20, default='operational', choices=[('operational','Operational / Ready'),('maintenance','Under Maintenance'),('blocked','Admin Blocked'),('inactive','Inactive / Decommissioned')])`
- `notes`: `TextField(blank=True)`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`


#### `Amenity` & `RoomCategoryAmenity`
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `name`: `CharField(max_length=100, unique=True)`
- `category`: `CharField(max_length=20, choices=[('comfort','Comfort'),('convenience','Convenience'),('safety','Safety & Security'),('service','Hotel Service')])`
- `description`: `TextField(blank=True)`
- `icon_name`: `CharField(max_length=50, default='check')`
- `is_property_wide`: `BooleanField(default=False)`
- `is_active`: `BooleanField(default=True, db_index=True)`
- `display_order`: `PositiveIntegerField(default=0)`

#### `RoomImage` (Flexible Media Storage)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `category`: `ForeignKey(RoomCategory, on_delete=models.CASCADE, related_name='images')`
- `image`: `ImageField(upload_to='rooms/%Y/%m/', null=True, blank=True)`
- `image_url`: `URLField(max_length=500, blank=True)`
- `caption`: `CharField(max_length=200, blank=True)`
- `alt_text`: `CharField(max_length=200, blank=True)`
- `is_primary`: `BooleanField(default=False)`
- `display_order`: `PositiveIntegerField(default=0)`
- `is_active`: `BooleanField(default=True)`

#### `RoomBlock` (`apps.inventory` - Operational Room Blocking)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `physical_room`: `ForeignKey(PhysicalRoom, on_delete=models.CASCADE, related_name='blocks')`
- `start_date`: `DateField(db_index=True)`
- `end_date`: `DateField(db_index=True)` *(Semantics: `[start_date, end_date)` night interval)*
- `reason`: `CharField(max_length=255)`
- `notes`: `TextField(blank=True)`
- `is_active`: `BooleanField(default=True, db_index=True)`
- `created_by`: `ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True)`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

#### `MaintenanceBlock` (`apps.inventory` - Physical Room Maintenance)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `physical_room`: `ForeignKey(PhysicalRoom, on_delete=models.CASCADE, related_name='maintenance_blocks')`
- `start_date`: `DateField(db_index=True)`
- `end_date`: `DateField(db_index=True)` *(Semantics: `[start_date, end_date)` night interval)*
- `maintenance_type`: `CharField(max_length=30, choices=[('repair','Repair & Fixtures'),('routine','Routine Service'),('deep_clean','Deep Cleaning / Sanitization'),('renovation','Major Renovation')])`
- `reason`: `CharField(max_length=255)`
- `notes`: `TextField(blank=True)`
- `is_active`: `BooleanField(default=True, db_index=True)`
- `created_by`: `ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True)`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

### 2.3 Reservation, Pricing & Booking Domain (`apps.bookings` & `apps.pricing`)

#### `Booking` (`apps.bookings` - Multi-Channel Reservation Core)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `booking_reference`: `CharField(max_length=30, unique=True, db_index=True)` (e.g. `'MG-2026-AB12C'`)
- `customer`: `ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True, related_name='bookings')` *(Nullable for walk-in / direct offline bookings)*
- `guest_name`: `CharField(max_length=150)`
- `guest_phone`: `CharField(max_length=20, db_index=True)`
- `guest_email`: `EmailField(blank=True)`
- `source`: `CharField(max_length=20, default='website', choices=[('website','Website / Direct Online'),('walk_in','Walk-in Reception'),('phone','Phone Inquiry'),('whatsapp','WhatsApp Direct'),('reception','Front Desk Booking'),('corporate','Corporate Contract')])`
- `status`: `CharField(max_length=20, default='held', choices=[('held','Temporary Hold'),('confirmed','Confirmed'),('checked_in','Checked In'),('checked_out','Checked Out'),('cancelled','Cancelled'),('expired','Expired'),('no_show','No Show')])`
- `check_in_date`: `DateField(db_index=True)`
- `check_out_date`: `DateField(db_index=True)` *(Night interval: `[check_in_date, check_out_date)`)*
- `total_adults`: `PositiveIntegerField(default=1)`
- `total_children`: `PositiveIntegerField(default=0)`
- `hold_expires_at`: `DateTimeField(null=True, blank=True, db_index=True)` *(Default 15 min lock from `BOOKING_HOLD_DURATION_MINUTES`)*
- `special_requests`: `TextField(blank=True)`
- `internal_notes`: `TextField(blank=True)`
- `is_overbooking`: `BooleanField(default=False)`
- `overbooking_reason`: `TextField(blank=True)`
- `created_by`: `ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True, related_name='created_bookings')`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

#### `BookingRoom` (`apps.bookings` - Category-Level Reservation Item & Physical Room Allocation)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `booking`: `ForeignKey(Booking, on_delete=models.CASCADE, related_name='booking_rooms')`
- `category`: `ForeignKey(RoomCategory, on_delete=models.PROTECT, related_name='booking_rooms')`
- `room_quantity`: `PositiveIntegerField(default=1)`
- `physical_room`: `ForeignKey(PhysicalRoom, on_delete=models.SET_NULL, null=True, blank=True, related_name='booking_assignments')` *(Optional initially, assigned by reception prior to check-in)*
- `assigned_at`: `DateTimeField(null=True, blank=True)`
- `assigned_by`: `ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True, related_name='assigned_rooms')`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

### 2.4 Pricing & Master Configuration Domain (`apps.pricing`, `apps.cms`, `apps.core`)

#### `RoomRatePlan` (`apps.pricing` - Master Data & Historical Versioning)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `category`: `ForeignKey(RoomCategory, on_delete=models.PROTECT, related_name='rate_plans')`
- `name`: `CharField(max_length=100, default='Standard Tariff')`
- `currency`: `CharField(max_length=3, default='INR')`
- `base_price_per_night`: `DecimalField(max_digits=10, decimal_places=2)` *(Confirmed baseline: AC ₹1,599, Non-AC ₹1,299)*
- `extra_adult_charge`: `DecimalField(max_digits=10, decimal_places=2, default=350.00)` *(Confirmed: ₹350)*
- `extra_child_charge`: `DecimalField(max_digits=10, decimal_places=2, default=300.00)` *(Confirmed: ₹300)*
- `late_checkout_hourly_rate`: `DecimalField(max_digits=10, decimal_places=2, default=150.00)` *(Confirmed: AC ₹150/hr, Non-AC ₹100/hr)*
- `effective_from`: `DateField(null=True, blank=True)`
- `effective_to`: `DateField(null=True, blank=True)`
- `is_active`: `BooleanField(default=True, db_index=True)`
- `created_at`: `DateTimeField(auto_now_add=True)`
- `updated_at`: `DateTimeField(auto_now=True)`

#### `TaxRule` (`apps.pricing`)
- `id`: `UUIDField(primary_key=True, default=uuid4, editable=False)`
- `name`: `CharField(max_length=100, default='GST')`
- `tax_rate`: `DecimalField(max_digits=5, decimal_places=2, default=5.00)` *(Confirmed baseline: 5% GST)*
- `tax_type`: `CharField(max_length=20, default='percentage')`
- `effective_from`: `DateField(null=True, blank=True)`
- `effective_to`: `DateField(null=True, blank=True)`
- `is_active`: `BooleanField(default=True, db_index=True)`

#### `BookingPriceSnapshot` (`apps.pricing` - Authoritative Immutable Pricing Snapshot)

- `booking`: `OneToOneField(Booking, on_delete=models.CASCADE, related_name='price_snapshot')`
- `currency`: `CharField(max_length=3, default='INR')`
- `room_subtotal`: `DecimalField(max_digits=12, decimal_places=2)`
- `extra_guest_total`: `DecimalField(max_digits=12, decimal_places=2)`
- `late_checkout_total`: `DecimalField(max_digits=12, decimal_places=2)`
- `miscellaneous_charges`: `DecimalField(max_digits=12, decimal_places=2)`
- `discount_amount`: `DecimalField(max_digits=12, decimal_places=2)`
- `taxable_subtotal`: `DecimalField(max_digits=12, decimal_places=2)`
- `tax_rule_name`: `CharField(max_length=100)`
- `tax_rate_percent`: `DecimalField(max_digits=5, decimal_places=2)`
- `tax_amount`: `DecimalField(max_digits=12, decimal_places=2)`
- `gross_total`: `DecimalField(max_digits=12, decimal_places=2)`
- `advance_amount_due`: `DecimalField(max_digits=12, decimal_places=2)` *(50% Razorpay advance split)*
- `balance_amount_due`: `DecimalField(max_digits=12, decimal_places=2)` *(50% Front Desk balance split)*
- `itemized_breakdown`: `JSONField(default=dict)` *(Complete structured line items, nightly rates, occupancy, and calculations)*
- `created_at`: `DateTimeField(auto_now_add=True)`
