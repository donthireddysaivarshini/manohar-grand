# Headless CMS & Dynamic Website Content Architecture

## 1. Vision & Architecture
The client requires complete control over website text, hero narratives, gallery photography, amenities descriptions, and contact information without modifying React frontend source code or redeploying code.

The backend provides a headless CMS API (`/api/v1/content/`) that delivers versioned, cached JSON representations of all marketing sections. The React frontend fetches this dynamic content with automatic fallback to built-in defaults if offline.

### 2.2 Photo Gallery Management (`GalleryMedia`)
- Category tagging: `exterior`, `ac_room`, `non_ac_room`, `amenities`, `neighborhood`.
- Fields: `title`, `image_url`, `display_order`, `is_featured`, `is_active`.
- Admin capabilities: Upload, reorder, caption, and toggle visibility.
