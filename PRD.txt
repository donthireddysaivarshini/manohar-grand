1. PRODUCT OVERVIEW

Manohar Grand is a hotel website and direct booking platform.

The product will initially be developed as a fully responsive frontend prototype using static/mock data.

The final product is expected to evolve into a full-stack hotel reservation system with:

Customer-facing hotel website
Room browsing
Date-based availability
Multiple-room booking
Online payments
Customer accounts
Booking management
Admin dashboard
Room inventory management
Pricing management
Offline bookings
Automatic inventory updates
Payment management
WhatsApp communication

The current development phase must focus only on the customer-facing experience.

No Django/backend/payment gateway/API integration should be implemented in Phase 1.

2. PRODUCT GOAL

The primary goal is to create a hotel website that feels like a premium, modern, trustworthy direct-booking hotel platform.

The website should:

Make the hotel look credible and established
Showcase rooms beautifully
Make room information easy to understand
Make availability easy to check
Make booking feel simple
Reduce unnecessary steps
Work exceptionally well on mobile
Look premium without becoming overly luxurious or complicated
Be structured so the frontend can later connect to a Django backend without major UI restructuring
3. DESIGN DIRECTION
Recommended visual direction

Manohar Grand should have a:

Premium contemporary hotel aesthetic with strong red branding, generous white space, high-quality photography and restrained typography.

It should NOT look:

like a generic hotel template
like a travel marketplace
like an e-commerce website
overly luxurious
overly corporate
excessively red
visually cluttered

The website should feel like a high-quality independent hotel website.

24. AVAILABILITY MODEL

36. UNIFIED INVENTORY

This is a critical architectural requirement.

Online and offline bookings must not have separate availability systems.

Both must eventually use:

              ROOM INVENTORY
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
      ONLINE                OFFLINE
      BOOKING               BOOKING
          │                   │
          └─────────┬─────────┘
                    ↓
             AVAILABILITY

This prevents double-booking.
